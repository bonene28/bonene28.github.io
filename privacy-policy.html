Alberto Marketplace Token

Privacy Policy

1. Introduction

This Privacy Policy explains how the Alberto Marketplace Token application ("AMT App") handles information when users access the application through the Pi Network ecosystem.

The AMT App is currently operated in the Pi Testnet development environment.

2. Information We Receive

When a user signs in through the Pi SDK, the application may receive information provided by the Pi Platform that is necessary to authenticate the Pioneer and operate the application.

This may include a Pi username and a Pi-provided user identifier.

3. Authentication

The AMT App uses Pi SDK authentication. The application does not request or store a user's Pi wallet passphrase or private keys.

4. Testnet Information

AMT balances, transactions, rewards, and other token-related information displayed during Testnet development are intended for testing purposes and may change as the system is developed.

5. Security

We take reasonable technical measures to protect application information. Private keys, wallet passphrases, and secret credentials must never be submitted to the AMT application.

6. Third-Party Services

The application may interact with Pi Network services and infrastructure required for authentication and Testnet development.

7. Changes to This Policy

This Privacy Policy may be updated as the Alberto ecosystem develops. Updated versions will be published on this page.

8. Contact

For questions concerning this Privacy Policy, please use the official contact information provided for the Alberto ecosystem application.
